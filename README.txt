Kitchen Pro V2.7 — Recipe Overview

NEW
- Tap anywhere on a recipe card (including its food icon or name) to open the full recipe.
- Full Recipe Overview shows the recipe icon prominently above/beside the recipe details.
- Ingredients and process steps can be read without starting Production or Recipe Lab.
- Production and Recipe Lab remain available as quick actions.
- Added ⋯ recipe options: Edit Recipe, Duplicate Recipe, Delete Recipe.
- Delete requires confirmation and warns when Recipe Lab test history will also be removed.
- Editing an official recipe increments its official version.
- “Better recipes. A brighter kitchen.” now opens Recipe Lab.

PRESERVED
- Kitchen Pro branding and home-screen support.
- iPhone network-first update fix from V2.6.3.
- V2.6.2 legacy recipe-data recovery/migration logic.
- Existing local-storage key is unchanged to protect device recipe libraries.

RECOMMENDED UPDATE PROCESS
1. Export JSON backup on each device.
2. Upload/replace all files from this package in GitHub.
3. Commit to main and wait for GitHub Pages deployment.
4. Refresh Kitchen Pro and confirm V2.7 Recipe Overview.
5. Verify recipes before doing new work.
